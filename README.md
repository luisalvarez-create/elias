# elias
Juegos

## Pulso Cúbico

Juego de ritmo y saltos: un cubo avanza solo y tú saltas los obstáculos.
Funciona en celular, tableta y computadora (`index.html`, sin instalar nada).

**Controles:** toca la pantalla, haz clic o pulsa `Espacio` / `↑` / `W` para saltar.
Mantén presionado para saltar sin parar. `Esc` o `P` pausa, `R` reinicia.

**Niveles:** Despegue, Circuito, Tormenta, Vértigo, Cielo Eléctrico (saltos en el aire),
Voltaje (portales de gravedad y velocidad) y el modo Infinito.

### Publicarlo con GitHub Pages

1. En GitHub abre **Settings → Pages**.
2. En **Source** elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guarda.
3. En uno o dos minutos el juego queda en `https://luisalvarez-create.github.io/elias/`.
